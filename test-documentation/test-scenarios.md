# Test Scenarios

## Overview

This document provides access to the test scenarios created for my practical manual QA project.

The project contains **52 test scenarios** designed to verify the application’s expected behaviour using positive, negative, and edge-case testing.

## Test Scenario Structure

Each test scenario includes the following information:

| Field | Description |
|-------|-------------|
| Scenario ID | A unique identifier assigned to the scenario |
| Requirement ID | The requirement covered by the scenario |
| Module | The application area being tested |
| Test Scenario | A high-level description of what will be tested |
| Priority | The importance of executing the scenario |

## Testing Approach

The test scenarios were designed to cover:

- Valid user actions
- Invalid user actions
- Required-field validation
- Error handling
- Boundary conditions
- Unusual user behaviour
- Business-critical functionality
- Application navigation
- User-session behaviour

These test scenarios demonstrate my ability to:

- Create traceable test scenarios
- Apply positive, negative, and edge-case testing
